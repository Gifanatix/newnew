# 🌍 Top 5 Richest Countries in 2026 — Remotion Motion Graphic

A 30-second YouTube motion graphic video built with [Remotion](https://remotion.dev).

## Video Structure

| Time | Scene | Content |
|------|-------|---------|
| 0–3 s | **Intro** | Glowing title reveal "Top 5 Richest Countries in the World 2026" |
| 3–25 s | **Countdown** | #5 Norway → #4 Switzerland → #3 Ireland → #2 Singapore → #1 Luxembourg |
| 25–30 s | **Outro** | CTA question + Subscribe animation + glow ending |

Each country card shows:
- 🏳 Country flag emoji
- Country name (large typography)
- Rank badge with gold/purple glow
- GDP per capita counting up
- Animated gradient bar growing left to right

## Style
- 1920×1080 @ 30 FPS
- Dark modern background with animated particles
- Smooth spring-physics animations
- Purple/gold gradient premium palette
- YouTube-ready

## Getting Started

```bash
# Install dependencies
npm install

# Open Remotion Studio (preview in browser)
npm start

# Render to MP4
npm run build
```

Rendered file will appear at `out/richest-countries-2026.mp4`.

## Requirements
- Node.js 18+
- Chromium (installed automatically by Remotion)
